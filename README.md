# ГАРТ — концепт-лендинг преміального фітнес-клубу

Демонстраційний сайт-приклад. Бренд «ГАРТ», ціни, розклад, адреса й тренери —
**вигадані**. Матеріал показується в межах домовленості про нерозголошення (NDA).

## Як відкрити

Двічі клацнути `index.html` — сайт статичний і працює без збірки й без інтернету.
Для «як у продакшені» (щоб коректно віддавались шрифти з відносних шляхів):

```bash
python3 -m http.server 4173
```

Далі — `http://localhost:4173`.

## Що всередині

```
index.html            весь контент і вбудована векторна графіка
assets/css/gart.css   токени, компоненти, адаптив
assets/js/gart.js     зони, розклад, шкала відпуску, валідація форми
assets/fonts/         Unbounded, Geologica, Martian Mono (self-hosted, woff2)
assets/img/           фотографії (webp) і вирізаний герой з альфа-каналом
PRODUCT.md            продуктова правда: аудиторія, обмеження, принципи
DESIGN.md             візуальна система, зібрана з готової збірки
.impeccable/          машинна копія системи (design.json)
```

Жодних CDN, аналітики, трекерів і зовнішніх запитів: сторінка повністю
самодостатня і відкривається офлайн.

## Ідея

Світлий фотоведений лендинг: теплий папір, великі скруглені плити,
чорні блоки-контрасти й один вольтовий акцент `#d8f84a`.
Фотографія веде — вирізаний атлет у герої, вертикальні знімки зон
зі зсувом по вертикалі, квадратні портрети тренерів.

Продуктова теза: клуб продає не залізо, а повний цикл —
навантаження, відновлення й контроль. Тому зона відновлення стоїть
у тижневому графіку поруч із тренуваннями, а не «як буде час».

## Що працює

- хореографія відкриття: заголовок розходиться, атлет підіймається, низ наздоганяє;
- фото зон і тренерів відкриваються шторкою знизу вгору, зберігаючи радіус;
- лічильники в смузі показників докручуються при появі;
- розклад на сім днів із навантаженням у крапках, за замовчуванням — сьогодні;
- форма запису з перевіркою імені, українського телефону й дати;
- повна клавіатурна навігація, видимий фокус, `prefers-reduced-motion`;
- контраст тексту перевірено: 215 текстових ролей, усі проходять WCAG AA;
- без JS сторінка лишається повністю видимою — анімації вмикає клас `js`.

## Що замінити на реальні дані

Назву й логотип клубу, адресу, телефони, пошту, ціни, розклад,
імена й кваліфікації тренерів, **відгуки** та посилання на соцмережі.

**Фотографії** — зі стокової бібліотеки Unsplash (вільна ліцензія,
комерційне використання без атрибуції). Для бойового сайту їх треба
замінити зйомкою реального клубу: у теці `assets/img/` лежать
`hero-athlete` (з альфа-каналом), шість `zone-*`, шість `coach-*`,
`band-box` і `card-video`.

Форма запису зараз лише валідує дані в браузері — під бойову версію
потрібен бекенд або інтеграція з CRM.
